# AI Vocabulary Telegram Bot
A Telegram bot that uses Google's Gemini API to analyze and return English vocabulary and automatically store structured results in Google Sheets.

I originally built this project as a personal tool to support my English and IELTS vocabulary study while experimenting with LLM APIs, structured outputs and external service integrations.

## Features
- English word analysis through Google Gemini
- Italian translation
- Grammar classification
- Synonym generation
- Example sentences with translations
- Structured AI outputs validated with Pydantic
- Automatic storage in Google Sheets
- Telegram-based interface
- Asynchronous handling of external API calls

## How it works
1. The user sends an Italian word to the Telegram bot.
2. The bot sends the word to Gemini.
3. Gemini analyzes the word and returns structured data.
4. The response is validated using a Pydantic schema.
5. The bot sends the result back to the user.
6. The information is automatically stored in Google Sheets.

## Tech Stack
- Python
- Google Gemini API
- Telegram Bot API
- Google Sheets API
- Pydantic
- gspread
- asyncio

## Example
Input:
enhance
Example output:
- Type: verb
- Translation: migliorare, potenziare
- Synonyms: improve, strengthen, boost
- Example sentences generated by Gemini
The result is also stored automatically in Google Sheets.

## Setup
Clone the repository:
bash
git clone https://github.com/DavidBraconi/ielts_bot.git
cd ielts_bot

Install the dependencies:   pip install -r requirements.txt
Create a .env file based on .env.example and configure your credentials.
Then run:   python bot.py

## Environment Variables
The application requires:
* TELEGRAM_BOT_TOKEN
* GEMINI_API_KEY
* SPREADSHEET_ID
* GOOGLE_CREDENTIALS_FILE

API keys and credentials are intentionally excluded from the repository.
